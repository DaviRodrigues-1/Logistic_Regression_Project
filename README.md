# ❤️ Cardiovascular Disease Prediction

## 📌 Overview

This project aims to predict the likelihood of cardiovascular disease in patients using machine learning techniques. The model is based on **Logistic Regression** and uses real-world health data.

The workflow includes:

* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Handling class imbalance with SMOTE
* Feature scaling
* Model training and evaluation

---

## 📊 Dataset Features

The dataset contains patient health information such as:

* **Age**
* **Gender**
* **Height**
* **Weight**
* **Glucose level**
* **Smoking status**
* **Alcohol consumption**
* **Physical activity**
* **Target variable:** Cardiovascular disease (1 = yes, 0 = no)

---

## ⚙️ Technologies Used

* Python
* Pandas
* Matplotlib / Seaborn / Plotly
* Scikit-learn
* Imbalanced-learn (SMOTE)

---

## 🧠 Model

The model used is:

* **Logistic Regression**

Techniques applied:

* Train-test split
* Standardization (StandardScaler)
* SMOTE for class balancing
