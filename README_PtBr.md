# ❤️ Previsão de Doenças Cardiovasculares

## 📌 Visão Geral

Este projeto tem como objetivo prever a probabilidade de doenças cardiovasculares em pacientes utilizando técnicas de Machine Learning. O modelo utilizado é a **Regressão Logística**, aplicado em uma base de dados real.

O fluxo do projeto inclui:

* Limpeza e tratamento de dados
* Análise exploratória (EDA)
* Balanceamento de classes com SMOTE
* Padronização de dados
* Treinamento e avaliação do modelo

---

## 📊 Variáveis do Dataset

A base contém informações como:

* **Idade**
* **Gênero**
* **Altura**
* **Peso**
* **Nível de glicose**
* **Fumante**
* **Consumo de álcool**
* **Atividade física**
* **Variável alvo:** Doença cardiovascular (1 = sim, 0 = não)

---

## ⚙️ Tecnologias Utilizadas

* Python
* Pandas
* Matplotlib / Seaborn / Plotly
* Scikit-learn
* Imbalanced-learn (SMOTE)

---

## 🧠 Modelo

Modelo utilizado:

* **Regressão Logística**

Técnicas aplicadas:

* Divisão treino/teste
* Padronização (StandardScaler)
* Balanceamento com SMOTE
